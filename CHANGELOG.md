# Changelog

All notable changes are documented here. The project follows Semantic Versioning where practical.

## 1.1.0 - 2026-07-21

- Reframed the repository as an evidence-aware bilingual mobile digital-twin and policy-experiment stack.
- Added original repository artwork and browser-verified screenshots of the mobile control plane and human experiment gate.
- Upgraded Flutter, FastAPI, ASGI, RL, test, and security-audit dependencies to pinned supported releases.
- Added strict request and artifact identifier validation, path containment, bounded payloads and training parameters, optional API-key middleware, production CORS checks, and distinct requester/approver enforcement.
- Redesigned the desktop experiment gate around public-replay evidence, chronological splits, five baselines, process-separated testing, and fail-closed execution.
- Expanded bilingual governance, contribution, security, support, release, citation, third-party, issue, CI, dependency and supply-chain documentation.

## 1.0.0 - 2026-07-20

- Established the Flutter/FastAPI mobile research workflow, public NOAA AIS aggregate, five policy baselines, held-out replay, Xiaoyi linkage, alerts, audit, and release verification scripts.

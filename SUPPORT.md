# Support / 支持范围

Use GitHub Discussions for setup, data-contract, mobile integration, and research-workflow questions. Reproducible software defects belong in Issues. Security vulnerabilities must follow [SECURITY.md](SECURITY.md).

安装、数据契约、移动端集成和研究流程问题可使用 GitHub Discussions；可复现软件缺陷请提交 Issue；安全漏洞必须按 [SECURITY.md](SECURITY.md) 私密报告。

This project does not provide a managed port-control service, site-integration SLA, safety certification, or emergency operational support. Production integration requires separate agreements, site validation, accountable operational ownership, and safety change management.

本项目不提供托管式港口控制服务、现场集成 SLA、安全认证或应急运行支持。生产接入必须另行完成协议、现场验证、责任划分与安全变更管理。

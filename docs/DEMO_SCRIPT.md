# 基于真实产物的演示脚本

演示前启动后端和 Flutter 客户端，并在设置页保持“界面讲解流程”关闭。该开关只影响导航提示，不得作为数据来源。

1. 打开“态势”：说明当前是 NOAA / MarineCadastre 长滩港邻近水域 2024-01-10 的公开历史 AIS 五分钟聚合，不是实时港口。
2. 打开“告警”：说明事件由后端历史测试段派生；断开后端可看到离线状态且不会出现本地假告警。
3. 打开“策略”：核验共享后端动态算法矩阵；核心6 RL + MPC必须存在，当前 V3.2 还显示 QR-DQN、TRPO、Recurrent PPO、ARS、FCFS。
4. 打开 `http://127.0.0.1:8000/rl-panel`，点击“批准并启动真实训练”。
5. 回到 App：进度、步数、回合、奖励和速率随 worker 实际运行更新；此时明确显示训练集且不渲染。
6. 训练完成后观察状态切到“测试评估”，随后出现 `dataset_split=test`、真实测试指标和轨迹帧数。
7. 点击三维推演：客户端先读 `/api/rl/strategies`，再把已登记模型交给 `/api/rl/simulate` 做留出集评测；没有真实 artifact 时不显示曲线或回放。
8. 查看策略候选：候选来自共享后端固定报告或相同数据/实验哈希的测试产物，并与声明基线对照。
9. 提交人工表态：默认公开回放只写 dry-run 审计，不显示生产已执行。
10. 打开“审计/回放”：复核 job、算法、数据哈希、测试指标和人工表态。
11. 回到首页点击“启动小懿智能联动”：确认页面显示 Web 共享后端、指令网关和 SHA-256 审计链的真实核验结果；小懿服务离线时不得显示在线。

演示口径：训练和算法是真的；数据是公开历史回放；动作响应和收益属于可复现实验沙箱；三维港区对象是未来 TOS/ECS/VTS 字段的界面槽位；没有真实港口适配器就没有生产下发。

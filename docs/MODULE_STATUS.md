# 模块实现状态

| 模块 | 当前驱动 | 实现与适用范围 |
| --- | --- | --- |
| 双端后端身份 | `GET /api/mobile/status` | Web / Flutter 固定读取 `port-dt-multi`，不再混用独立实验后端 |
| RL 算法选择 | 共享后端动态能力注册表 | 核心 6 RL + MPC 必须存在，V3.2 扩展为 10 RL + MPC + FCFS |
| 训练进度 | SB3 callback / PID 校准 trial | 由实际环境步和 trial 驱动，不使用计时器或插值进度 |
| 训练曲线 | worker 写出的 history | 没有历史数据时不绘制曲线 |
| 测试回放 | 独立 test split 轨迹 | 训练完成后才可读取 |
| 策略候选 | 固定业务报告或已登记测试 artifact | 缺少风险标签时显示 n/a，不以 0 表示低风险 |
| 态势摘要 | NOAA AIS 历史测试段 | 公开历史回放；风险为确定性派生点值，不冒充未来预测、置信区间或实时态势 |
| 告警 | 后端历史派生 + WebSocket | 断线不生成本地业务告警 |
| 端内通知 | WebSocket 告警事件批处理 | 只形成应用内通知；未接 FCM/APNs 时不暴露空实现冒充系统推送 |
| 3D 港区 | Flutter 代码绘制的接口布局 | 只显示真实 AIS 快照字段；泊位/船舶/岸桥/堆场/AGV 缺失字段显示“未接入” |
| 告警重规划 | 已完成 test artifact + 服务器审计 | 无匹配产物返回 409；超时不会生成成功回执 |
| 态势控制参数 | `POST /api/control/config` | 后端真实记录；固定为客户端审阅范围，不冒充生产控制 |
| 执行 | 移动表态与南向执行分离 | 移动接口固定 dry-run；生产动作只能进入共享后端双人门禁 |
| 审计 | 本地缓存 + 服务器原子证据与 SHA-256 前向链 | 500项基准中300条事件链全部通过；生产仍应接不可变日志/签名系统 |
| 回放复盘 | 相邻审计记录与真实提交/回执快照 | 只展示记录顺序和差异，不把相邻记录归因为干预效果 |
| 小懿协同 | `GET /api/rl/integration/health` + `POST /api/assistant/actions/execute` | 页面导航保留本地可用性；跨端动作必须显示 Web dry-run 回执，真实小懿离线时明确显示后端证据兜底 |
| 图片资产 | Flutter Material 图标 | 已移除来源不明的 PNG |
| 访问凭证 | 运行期内存 + Dio 请求头 | 只标记“已配置、未验证”；服务器 2xx/鉴权响应才是有效性证据，不持久化私密 token |
| API 边界 | 可选 API key + 请求体/参数上限 | 研究模式可关闭；live/production 强制 32+ 字符 key 和非通配 CORS |
| 实验标识与产物路径 | 严格 ID 正则 + resolved-path containment | 拒绝路径穿越、绝对路径、目录逃逸和越界模型/历史产物 |
| 人工审批 | requester / approver 分离 | 同一身份不能批准自己的实验申请；企业部署仍需接入组织身份和授权系统 |

## 现场集成条件

- 算法结果来自公开数据与离线环境，不代表真实港口的调度收益或安全认证。
- NOAA AIS 实验环境不模拟真实 AGV、岸桥、泊位或船期设备响应。
- 三维布局是接口示意，不对应特定港口对象或班次。
- 环境变量只配置接口，不能替代现场数据治理、网络隔离、权限审批和安全联锁。

这些事项需要具体港口的数据协议、现场校准、回放对照、影子运行、人工验收和独立安全评估。

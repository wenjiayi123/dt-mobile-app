# PortAI 移动端真实链路口播稿

（点击：态势）

当前看到的是美国长滩港邻近水域 2024 年 1 月 10 日的 NOAA 公开 AIS 历史数据，系统按五分钟聚合船舶数量、航速、停止比例和交通密度。它不是港口实时 TOS 或设备遥测，页面会始终保留这个证据标签。

（点击：策略）

这里与 Web 端共享四种强化学习算法 SAC、PPO、TD3、DQN，以及一个控制理论基线 MPC。选择算法并提交训练申请后，电脑端不同操作者必须人工批准。

（点击：提交训练申请；电脑端点击：批准并启动真实训练）

现在后端独立进程只读取训练时间段，关闭图形渲染。移动端进度条来自训练器的真实步数、回合、奖励和每秒速率，不使用计时器伪造。

（等待：测试评估）

训练已经结束，策略被冻结。系统现在才加载从未参与训练的测试时间段，记录每一步动作、收益、拥堵、冲突风险与安全余量，生成可回放轨迹。

（点击：播放测试轨迹）

这里播放的是刚才 job 的测试 artifact。没有完成的测试产物，页面不会补一条平滑曲线或本地三套候选。

（滑动至：候选策略）

候选指标来自共享后端的固定业务报告或已登记留出测试产物，可与同合同声明基线比较。系统级收益属于数字孪生反事实，不是生产港口实测KPI。

（点击：确认方案；点击：提交）

当前数据模式是公开历史回放，所以这次人工表态只写入 dry-run 审计，不会显示成已经控制现场。只有验证过的实时数据网关和执行适配器同时开启，并获得适配器真实回执，系统才允许标记为生产确认。

（点击：审计）

审计记录保留算法、job、数据哈希、测试指标、人工表态和下发边界。到这里完成的是一条可运行、可复现、不会把演示包装成生产的开源链路。

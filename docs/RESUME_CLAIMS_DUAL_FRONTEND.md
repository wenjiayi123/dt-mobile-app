# 双端系统简历证据

## 算法与数据可信度

共享后端构建 `port_ops_v2` 港口强化学习环境，包含37维观测、5维建议动作、
12类国际港口现实因素及逐因素可用性掩码。BTS 与 NOAA 洛杉矶港 2021
公开基准形成87,459个六分钟时步、262,347条独立公共原始观测，按
69,967/17,492时序划分，并登记42条短缺口插值；公开数据覆盖5/12类因素。

SAC、PPO、TD3、DQN、A2C、TQC分别完成3个随机种子×10,000步无渲染训练，
并在10个确定性留出窗口评测；MPC按相同窗口单独登记，共形成18组正式RL
训练证据和1组控制基线证据。移动端实时核验算法集合、环境空间、数据指纹
和证据数量，不复制训练产物。

## 系统级业务指标

共享后端以 MPA 新加坡 2020–2025 官方月度吞吐量与集装箱船到港量为锚点，
构造 `public_port_ops_v1` 52,608 条连续小时驱动记录，按 35,064 train /
8,784 validation / 8,760 test 时序隔离。2025 最终测试相对“静态 FCFS +
固定能源时刻表”得到：

- 泊位有效利用率 83.63%→91.09%，提升 7.45 个百分点（相对 +8.91%）；
- 平均待泊时间缩短 16.94%；
- 情景用电成本降低 11.80%；
- 365 个完整测试日完成 2,000 次成对 bootstrap，另复算 27 组参数敏感性。

这些是 Web 与移动双端共同使用的系统级数字孪生结果，不是移动端单独收益，
也不是港口实测 KPI。

## 移动端可靠性指标

共享后端固定执行 500 项本地集成操作：100 次新表态、100 次精确重试、
100 次冲突幂等键重用、100 次越权生产下发尝试、100 次审计上传。

- 重复提交抑制率、冲突键阻断率、越权下发阻断率和审计接收率均为 100%；
- 300 条服务端 SHA-256 前向审计事件全部通过；
- 形成 200 个唯一回执，生产执行回执为 0。

这组数字是确定性 API 语义与本地持久化测试，不是现场网络 SLA 或设备执行
成功率。完整配置、报告和复验脚本位于 Web 后端仓库。

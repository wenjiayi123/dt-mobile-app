# 安全说明

## 默认安全姿态

- 后端默认只监听 `127.0.0.1`；Docker 示例显式监听容器网络。
- 公开回放、未验证 live 数据或未验证执行适配器都不能生产下发。
- 客户端不包含港口密钥、数据库凭证或长期 root token。
- 告警断线为离线状态，不通过本地 mock 掩盖故障。
- 训练请求绑定服务器数据 SHA-256，并限制最大训练步数。
- 重规划审阅必须绑定同数据哈希的完成测试产物；客户端控制参数不会改变生产控制。
- 审计服务为每个 JSONL 事件写入 `previous_hash` 与 `event_hash`。

## 生产部署责任

后端在研究模式可不配置 API key；`live` 或 `production` 模式必须配置至少 32 字符的 `PORTAI_API_KEY`，并拒绝通配 CORS。部署方仍必须在网关层实现 OIDC/OAuth2、角色权限、速率限制、TLS、证书/域名校验、密钥轮换和网络分区。本地 API key 与人工审批页都不是完整的企业身份系统。

Flutter 示例 token 当前只保存在运行时状态，输入框默认隐藏且不启用自动更正；生产移动端必须改为 Keychain/Keystore 安全存储，禁止把 token 放进源码、`--dart-define`、日志或截图。

执行适配器使用 `Idempotency-Key`，但港口适配器仍必须实现幂等、允许动作白名单、边界校验、双人审批、超时、撤回/回滚和现场安全联锁。`PORTAI_EXECUTION_ADAPTER_VERIFIED=true` 只是部署声明，不是软件自动认证。

## 审计限制

本地 SharedPreferences 不是防篡改存储。服务器哈希链能发现重排或修改，但不能防止有文件写权限的人整体重写链。生产应将事件同步到访问受控、带服务端签名或 WORM 保留策略的审计系统。

## 报告漏洞

请不要在公开 Issue 中提交密钥、现场拓扑、船舶身份数据或可利用细节。通过仓库维护者提供的私密安全渠道报告，并附最小复现、影响范围和建议缓解方式。

# 港航演示中心

这是六个本地港航项目的 macOS 桌面总控源码。构建后可通过桌面 `港航演示中心.app` 单独启动任一系统，或按依赖顺序一键启动全部系统。

## 启动顺序

1. 港口数字孪生 V3.2，等待真实健康回执。
2. 舷鸥 · GullMate，核验服务身份。
3. 能碳驾驶舱。
4. 马六甲港口推演。
5. PortAI 移动端。
6. Godot 航行模拟器。

总控不会同时盲目拉起六个项目；每一步只有通过端口、服务身份和健康回执后才会继续。

如果系统应用包在窗口运行期间被重新构建，总控会先退出旧壳再打开新版，避免 LaunchServices 只激活旧进程。PortAI 的原生入口还会携带构建版本参数，防止 WebKit 命中上一轮演示资源。

## PPT 直接启动协议

构建后的六个子系统应用分别注册以下本机协议，供 PowerPoint 的“启动系统”按钮直接调用：

- `xianyi-launch-xiaoyi://open`
- `xianyi-launch-port://open`
- `xianyi-launch-mobile://open`
- `xianyi-launch-sailing://open`
- `xianyi-launch-malacca://open`
- `xianyi-launch-energy://open`

这些协议只在安装了本演示中心的 macOS 本机生效；其他系统仍可正常打开 PPT，并使用 HTTPS 演示与 GitHub 链接。

## 真实停机

- 每个独立窗口都有“停止并退出系统”按钮；红色关闭按钮、Cmd+Q 和 Dock 退出均执行后台清理后再退出。
- 复用既有服务时也会核验监听进程、项目目录与进程身份并接管，进程记录丢失后仍可安全发现本项目残留。
- “全部停止”先取消窗口的启动与自动恢复，再核验并停止后台及子进程；即使原始 `make` / `run.sh` 包装进程已经退出，也会按“已登记回环端口 + 对应项目真实工作目录”恢复识别孤儿进程树。项目目录之外的同端口进程仍会保留，最终必须再次检查实际端口，不能仅凭空 PID 目录宣称成功。
- 移动端与数字孪生共用 8000 后端，最后一个使用它的系统退出时才停止；移动端自己的 8765 服务随窗口退出。
- 窗口关闭但后台尚在运行时，总控明确显示“后台仍在运行”，避免与可切回的在线窗口混淆。

## 构建

```bash
bash tools/desktop_demo_center/build.sh
```

构建脚本会生成并临时签名 `~/Desktop/港航演示中心.app`。项目路径与启动命令位于 `configs/`，在其他机器上使用前需根据实际目录调整。

详细使用方式见 `使用说明.txt`。

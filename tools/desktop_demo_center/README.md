# 港航演示中心

这是六个本地港航项目的 macOS 桌面总控源码。构建后可通过桌面 `港航演示中心.app` 单独启动任一系统，或按依赖顺序一键启动全部系统。

## 启动顺序

1. 港口数字孪生 V3.2，等待真实健康回执。
2. 小懿 AI，核验服务身份。
3. 能碳驾驶舱。
4. 马六甲港口推演。
5. PortAI 移动端。
6. Godot 航行模拟器。

总控不会同时盲目拉起六个项目；每一步只有通过端口、服务身份和健康回执后才会继续。

## 真实停机

- 每个独立窗口都有“停止并退出系统”按钮，红色关闭按钮也进入同一流程。
- “全部停止”会先核验 PID 和命令签名，递归停止子进程，必要时强制退出，并再次确认无残留。
- 移动端只停止自己的 8765 界面服务，不会误杀共享的 8000 数字孪生后端。

## 构建

```bash
bash tools/desktop_demo_center/build.sh
```

构建脚本会生成并临时签名 `~/Desktop/港航演示中心.app`。项目路径与启动命令位于 `configs/`，在其他机器上使用前需根据实际目录调整。

详细使用方式见 `使用说明.txt`。

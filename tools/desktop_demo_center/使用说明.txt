港航演示中心

1. 双击桌面的“港航演示中心.app”。
2. 点击任一系统的“打开系统”，会启动真实本地服务并在独立 macOS 窗口中显示，不打开 Chrome 或 Safari。
3. 点击“全部启动”可依次打开六个系统；移动端会自动确保港口数字孪生 API 已就绪。
4. 点击“全部停止”只会停止由本启动器记录并核验身份的后台进程。
5. 每个独立窗口标题栏都有“停止并退出系统”；点击红色关闭按钮也会进入同一真实停机流程，不会只关表面窗口。
6. Flutter 移动端使用已核验的 release 构建；小懿 AI 首次加载本地模型可能稍慢，窗口会显示当前进度。
7. 日志位于：~/Library/Application Support/港航演示中心/Runtime/logs/

技术边界：Flutter 移动端和原 Web 系统运行于原生无浏览器外观的 WKWebView 桌面壳，真实后端、接口与联动合同保持不变；航行模拟器直接运行 Godot 独立主场景。当前机器缺少完整 Xcode/CocoaPods，因此未将 Flutter 编译为纯 macOS Runner。
